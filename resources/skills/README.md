# PACT role skills

The skills PACT gives to the agents it launches with a role (orchestrateur, spec, design, dev,
test, recap), plus the shared hand-off contract. They ship beside the app (`extraResources`), are
copied per agent at launch and never written to a CLI's own configuration.

Suite, common contract and the delivery to each CLI: `specs/004-delivery-chain/contracts/skills.md`.
